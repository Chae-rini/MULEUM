# 물음 (MULEUM) | Codex 입문용 시작 패키지

## 무엇이 들어 있나요?

- `muleum-web-prototype.html`: 이전 대화에서 만든 **로컬 HTML 시제품**. 실제 서버 기능 없음.
- `PRODUCT_BRIEF.md`: 제품 철학과 베타 목표 및 사용자 역할.
- `AGENTS.md`: Codex가 이 프로젝트를 작업할 때 따를 규칙.
- `CODEX_PROMPTS.md`: 단계별로 복사해 쓸 프롬프트.

## macOS에서 처음 실행하기

1. 이 ZIP 파일을 내려받고 압축을 풉니다.
2. 압축이 풀린 `muleum-codex-starter` 폴더를 `Documents/Projects/` 같은 안전한 위치로 옮깁니다.
3. `muleum-web-prototype.html`을 Safari로 열어 원래 디자인과 흐름을 확인합니다.
4. 최신 ChatGPT 데스크톱 앱을 열고 Codex로 전환합니다.
5. 작업 대상 폴더로 **압축을 푼** `muleum-codex-starter`를 선택합니다.
6. `CODEX_PROMPTS.md`에서 **1단계 프롬프트**를 복사해 Codex에 붙여넣습니다.
7. 계획과 결과물을 검토한 뒤, 기능 구현·실행·테스트를 진행합니다.

처음에는 GitHub/Supabase/API 키 없이 로컬 화면과 기능부터 만들 수 있습니다.

## 주의사항

- 이전 HTML은 **시연 자료**이며 영구 저장, 접근권한, 인증, AI 연결이 없습니다.
- 지금은 가명 또는 가상의 예시만 사용하세요. 실제 미성년자 기록/일기/이름/연락처를 넣지 마세요.
- 인증·권한·개인정보 설정을 검증하기 전에는 외부 베타 사용자에게 제공하지 않습니다.
- `NEXT_PUBLIC_` 접두어가 붙는 변수에는 비밀키를 넣으면 안 됩니다.
- 변경 내용을 이해할 수 있도록 Codex에 설명과 테스트 결과를 요구하세요.
