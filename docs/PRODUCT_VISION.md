# 물음의 제품 비전

상태: Phase 0·1 기준 문서. 현재 구현은 가상 데이터 기반 로컬 시제품이며 실제 회원 서비스가 아니다.

## 정체성과 목적

**물음 (MULEUM)** — 모든 배움은 하나의 질문에서 시작된다.

물음은 질문을 매개로 사람이 만나 서로 배우고, 각자의 삶을 선택하도록 돕는 초대 기반 비공개 교육·학습 공동체다. 과외 관리와 학습 기록은 이 관계를 돕는 수단이며, 플랫폼의 목적 자체가 아니다. 인간 중심 (Human-Centered) 원칙을 기능과 운영의 판단 기준으로 삼는다.

초기에는 중·고등학생, 과외 선생님, 학부모를 대상으로 시작한다. 장기적으로 졸업생, 승인된 조교, 다양한 학문과 직업의 성인 학습자까지 배움의 연결을 넓힌다. 특정 진로·성공 기준·꿈을 강요하지 않는다.

## 가치가 제품에서 드러나는 방식

| 가치 | 제품 결정 | 확인할 질문 |
| --- | --- | --- |
| 자율성 | 목표를 학생이 직접 정하고 일기 작성은 선택 | 목표를 거절하거나 조정해도 불이익이 없는가? |
| 질문 중심 | 질문을 답변 여부나 점수로 서열화하지 않음 | 답이 없는 질문도 존중하는가? |
| 신뢰 | 개인 기록과 공동 게시판을 분리 | 저장만 했는데 다른 사람에게 게시되지 않는가? |
| 관계 | 담당 선생님과 승인된 참여자가 사람의 답변을 제공 | 자동 답변이 사람의 대화를 가로막지 않는가? |
| 사생활 | 개인 일기와 학부모 리포트의 데이터 경로 분리 | 일기 원문이 리포트 생성의 자동 입력이 되지 않는가? |
| 선택적 공동체 | 졸업 후 참여·후배 지원을 의무화하지 않음 | 탈퇴와 비참여를 존중하는가? |

## 공개 공간과 회원 공간

- `/`: 철학, 질문 중심 교육, 조정 가능한 120분 모델, 사람의 관계, 공동체 비전, 비공개 베타 준비 안내. 실제 학생 기록이나 내부 운영 명단을 불러오지 않는다.
- `/app`: 향후 회원 전용 앱의 위치. 현재는 누구나 접근 가능한 **가상 데이터 시연**이며 인증과 서버 권한이 없다. 초대 기반 서비스가 이미 운영 중이라고 표현하지 않는다.
- 공개 페이지에 실제 회원가입·상담정보 입력·대기자 수집 폼을 만들지 않는다.
- 공개 소개에서 검증되지 않은 성적 향상, 합격 후기, 허구의 선생님 프로필을 사용하지 않는다.

## 우선순위

1. 사람의 교육철학과 운영 원칙을 문서와 화면 구조로 연결한다.
2. 기존 학습 도구를 보존하고 사람 중심 공지·질문·관계·수업 기록의 MVP를 검증한다.
3. 서버 인증·초대·최소 권한·학생 간 격리와 보호 절차를 갖춘다.
4. 보안 및 운영 검증을 통과한 뒤 제한된 베타를 운영한다.

졸업생 공동체는 초기 학습 앱 내부에 개발하지 않는다. 회원 계정의 졸업 상태와 승인 역할만 유지하며, 장기적으로 별도 사이트 또는 외부 서비스를 검토한다. 현재 운영하지 않는 라운지 링크는 표시하지 않고 학습 기록·개인정보를 자동 전송하지 않는다. AI 질문 코치와 결제·자동 정산도 현재 필수 기능이 아니다. 향후 AI 도입 여부는 사람의 배움에 실제로 도움이 되는지 별도로 판단한다.

## 성공과 비목표

성공은 학생이 질문을 자신의 말로 만들고, 다음 행동을 선택하며, 선생님과 신뢰할 수 있는 대화를 이어갈 수 있는지로 확인한다. 평가 방법과 조사 주기는 베타 전 합의한다.

체류 시간, 연속 출석, 경쟁 순위, 자동 성격·정신건강 분류를 성공 기준이나 제품 기능으로 사용하지 않는다. 학생의 결정을 AI가 대신 내리지 않는다.
