# 교육철학과 경험 설계

## 기본 약속

교육은 학생의 성적뿐 아니라 스스로 선택하고 책임질 수 있는 삶을 돕는다. 학생에게 꿈·목표·진로·행복의 형태를 정해 주지 않는다. 학생이 중요하게 생각하는 것을 듣고 선택의 이유와 결과를 탐색한다.

선생님은 감시자가 아니라 대화와 피드백으로 자율성을 돕는 사람이다. 학부모와의 신뢰는 학생의 모든 기록을 공개하는 방식이 아니라, 합의한 학습 방향을 필요한 범위에서 공유하는 방식으로 만든다.

## 질문 → 탐구 → 행동 → 성찰

1. 질문: 왜, 어떻게, 정말 그런가. 과목·독서·철학·일상의 질문을 모두 존중한다.
2. 탐구: 근거, 다른 관점, 확인할 방법을 사람과 함께 살펴본다.
3. 행동: 학생이 가능한 작은 실천을 선택한다. 타인이 정한 양을 일괄 부과하지 않는다.
4. 성찰: 성공·실패 점수보다 경험과 다음 선택을 돌아본다. 질문이 남아 있어도 괜찮다.

화면에서는 “정답을 제출하세요”보다 “어떻게 생각했나요?”를, “미달”보다 “다음에 조정할 점”을 사용한다. 칭찬이나 알림을 통해 참여를 강요하지 않는다.

## 조정 가능한 120분 기본안

| 과정 | 기본 시간 | 목적 |
| --- | ---: | --- |
| 인사와 주간 리뷰 | 5분 | 일상과 생각 이해 |
| 독서 | 10분 | 독해와 새로운 관점 |
| 영단어 학습 | 10분 | 수준에 맞는 인출 연습 |
| 핵심 수업 | 55분 | 개념과 원리 이해 |
| 휴식 | 5분 | 집중력 회복 |
| 독립 문제풀이 | 25분 | 스스로 사고하고 적용 |
| 오늘의 리뷰 | 10분 | 질문·성찰·다음 목표 |

합계 120분. 이는 확정 교육과정이 아닌 기본 템플릿이다. 독서와 어휘 학습의 시간·분량·적합성은 학생, 과목, 선생님에 따라 조정해야 한다. 영어 단어 50개 같은 획일적 수량을 의무로 만들지 않는다.

현재 체크리스트는 기존 7단계 고정형을 보존한다. 편집 기능을 구현했다고 표시하지 않는다. 향후 `LessonTemplate`을 버전별로 관리하고 수업 기록에 당시 단계와 시간을 복사하여, 이후 템플릿 변경이 과거 기록을 바꾸지 않게 한다. 수업별 총시간은 단계 합으로 계산하며 120분과 다르면 조정 사실을 보여 주되 잘못된 수업으로 단정하지 않는다.

## 오늘의 물음과 공동 질문게시판

- 수업 끝 질문은 선택적으로 남긴다. 교과 관련 질문만 허용하는 제한을 두지 않는다.
- `나의 물음`은 개인 기록이며 공동 게시판의 초안과도 구분한다.
- 향후 게시 시 학생이 대상 범위를 명시적으로 선택하고 공개 내용을 미리 확인한다.
- 답변은 담당 선생님, 승인된 조교, 해당 공간 참여가 허용된 구성원이 한다.
- 후속 질문과 근거의 수정을 지원한다. 질문 상태는 작업 흐름이며 학생의 능력 등급이 아니다.

## 5분 일기

작성·빈도·분량은 선택이다. 기본 공개 범위는 본인만이며, 선생님·학부모·관리자에게 일괄 열람 권한을 주지 않는다. 상담 기록과도 별도 분류한다. 향후 공유를 도입한다면 원문 자동 연결 대신 학생이 선택한 발췌·목적·대상·철회 정책을 먼저 설계한다.

일기를 자동 분석하여 의지, 성격, 정신건강, 감정을 판정하지 않는다. 외부 AI API에 자동 전송하지 않는다. 현재는 실제 사생활 보호가 가능한 인증이 없는 로컬 데모이므로 가상 내용만 사용한다.

## AI의 경계

AI는 자료 정리, 검색·분류 보조, 공지 초안, 수식·문서 정리, 일정 지원 등 보조 역할을 검토할 수 있다. 사람이 초안을 검토·승인한다. 교육적 결정과 학생의 감정·의도를 AI가 독단적으로 판단하지 않는다.

실제 AI 모듈은 아직 없다. 향후 서버 전용 연동 모듈, 허용 입력 목록, 사람이 확인하는 출력 절차를 별도로 추가한다. 학습 기록의 저장과 외부 AI 전송은 별도 동의·처리 목적을 가진 작업으로 설계한다.

## 디자인 점검 기준

아이보리·포레스트 그린·세이지 그린, 읽기 쉬운 한국어, 넉넉한 여백을 사용한다. 모바일 왼쪽 메뉴와 PC 상단 메뉴를 유지하고 키보드·화면 낭독기 탐색을 지원한다. 랭킹, 강제 연속 출석, 경쟁 배지, 학생을 감시하는 점수판은 추가하지 않는다.
