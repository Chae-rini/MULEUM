# 단계별 개발 계획

현재 목표는 **Phase 0과 Phase 1**이다. 기존 v0.1의 일부 로컬 기능이 Phase 2 항목과 겹쳐도 Phase 2 전체나 실제 서비스 보안이 완료된 것은 아니다.

## Phase 0 — 분석

기존 파일, 실행 환경, 저장 형식, 디자인, 테스트, Git 변경 사항을 확인한다. 초기 기획서와 HTML을 보존하고 최근 메뉴 변경을 재사용한다. 결과는 `ARCHITECTURE.md`에 기록한다.

완료 기준: 재사용할 기능, 누락된 보안, 기술 부채와 변경 경계를 설명할 수 있다.

## Phase 1 — 문서와 웹사이트 골격

- 비전·교육철학·운영 모델·아키텍처·권한·로드맵 6개 문서.
- 공개 `/`와 회원 공간 시연 `/app` 분리.
- 실제 주소 기반 메뉴, 모바일 왼쪽 메뉴, PC·태블릿 상단 메뉴.
- 기존 질문·목표·일기·수업·메모·리포트 예시 재사용.
- 공지·질문게시판·교육팀·졸업생·운영 공간의 시연 골격.
- 복수 역할·연령·재학 상태·승인 관계의 독립 타입 계약.
- 정원 계산 규칙과 경계 테스트. 아직 서버 정원 집행은 아님.
- 로그인·API·결제·개인정보 수집 없이 실행·빌드·회귀 검증.

완료 기준: 공개 소개에는 회원 기록이 없고, 화면별 구현 상태가 정확히 표시되며, 새 경로에서도 기존 로컬 기록이 유지되고 테스트를 통과한다.

## Phase 2 — 사람 중심 핵심 MVP

다음 단위로 나눠 진행한다.

1. 회원·관계·자료 공개 범위와 상세 사용자 흐름 확정.
2. 공지 작성·분류·대상 선택; 질문게시판 작성·답변·후속 질문·상태.
3. 주 담당 교사 관계, 수업 기록과 학생 피드백, 오늘의 물음.
4. 조정 가능한 수업 템플릿과 과거 수업 기록의 호환성.

권한 정책 미확정 기능은 가상 데이터 시제품으로만 구현하고 실제 운영과 구분한다. 개인 물음의 게시판 자동 게시, 일기의 리포트 자동 포함은 하지 않는다.

완료 기준: 사람의 질문·답변·피드백 흐름과 잘못된 입력·빈 상태·오류 복구를 검증한다. 실제 서버와 권한이 없으면 완료 보고에 이를 명시한다.

## Phase 3 — 인증과 비공개 운영

외부 연결 승인 후 초대제 가입, 서버 인증, 복수 역할 승인, 학생별 관계 인가, 데이터베이스 RLS, 비공개 파일, 관리자 업무 권한을 구현한다. 초대 수락과 정원 변경의 동시성 테스트를 포함한다.

실제 미성년자 사용 전에 동의·보호자 관계 확인·보관 및 삭제·신고와 대응 정책을 확정한다. [ACCESS_CONTROL.md](ACCESS_CONTROL.md)의 보안 검증을 통과하지 못하면 Phase 4로 이동하지 않는다.

승인 전에는 Supabase 프로젝트 생성, 키 저장, 배포, 실제 사용자 초대, 개인정보 수집을 실행하지 않는다.

## Phase 4 — 제한된 베타

보안·운영 기준을 충족한 뒤 승인된 선생님과 학생을 초대한다. 수업과 게시판 사용성을 관찰하고 교육팀 피드백을 반영한다. 문제 발생 시 초대 중지·권한 철회·자료 처리 절차를 사용한다.

처음부터 정원 전체를 채우는 것이 목표가 아니다. 초기 초대 인원과 검증 기간은 별도 결정한다. 성적 향상 수치나 합격 후기를 검증 없이 홍보하지 않는다.

## 후속 검토 영역

- 졸업생 공동체: 초기 학습 앱 범위 밖이다. 학습 DB에는 졸업 상태와 역할만 보존한다. 향후 별도 웹사이트나 외부 서비스로 검토하며, 실제 운영처 확정 전에는 라운지 메뉴나 링크를 노출하지 않는다. 학습 기록과 별도 데이터 저장소를 사용하고 개인정보 자동 전송을 하지 않는다. 세부 경계는 `ACCESS_CONTROL.md`를 따른다.
- AI 보조: 사람 중심 활동을 지원하는 자료·문서·운영 기능부터 필요성 검토. AI 질문 코치는 후순위.
- 외부 영상·화이트보드: 직접 영상 서버 개발 없이 승인된 링크 연동 검토.
- 회계·정산: 수수료·환불·납부 정책 확정 후. 초기 자동 청구 없음.
- 투두메이트: 별도 검토 사항. 이번 작업에 API·계정 연동을 포함하지 않음.

## 사용자에게 결정받을 항목

승인권자, 초대 만료·정원 예약, 활성 학생 기준, 보호자 연결·동의, 연령 확인, 조교 활동 범위, 교사 메모 공유, 개인정보 보관·삭제, 수수료·정산, 실제 베타 시작 시점은 아직 미확정이다. UI의 예시 값을 확정 정책으로 취급하지 않는다.
