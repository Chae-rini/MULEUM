# 디자인 시스템 — Soft Blue Library

## 콘셉트 — 구름 위에 떠 있는 도서관

낮에는 태양빛, 밤에는 별빛이 비추고, 두 빛이 함께 있다. Soft Blue Library를 바꾸지 않고 심화한다.

- **라이트 = 낮, 구름 위**: 위는 하늘색이고 아래로 갈수록 흰 구름층으로 이어진다. 도서관이 구름 위에 떠 있다.
- **다크 = 밤, 별과 은하를 보는 도서관**: 다음 작업이다. 이번에는 토큰 이름만 준비했다(`--reading-light`, `--star`).
- **공존 원칙**: 낮에도 별(✦ 모티프)이 작게 남는다. 밤에도 태양빛이 독서등(따뜻한 종이색 `--reading-light`)으로 남는다.
- **장식이 있는 곳**: 풍경 장식(하늘·구름·✦)은 공개 홈, 로그인·초대·첫 로그인 확인 화면에만 둔다. 회원 학습 공간(질문·일기 등)은 장식을 최소화해 읽기에 집중하게 한다.
- **장식 규칙**: 모두 CSS와 인라인 SVG로만 만든다(`components/sky.tsx`). 이미지나 외부 요청은 쓰지 않는다. 화면낭독기에는 숨긴다(`aria-hidden`). 장식 위의 모든 글자는 대비 기준(본문 4.5:1, 큰 글자 3:1)을 지킨다. 움직임은 `prefers-reduced-motion`에서 완전히 멈춘다.

### 라이트 모드에서 쓰는 곳 (2026-10-24)

- **홈 히어로**
  - 도서관 사진은 유지하고, 남색 덮개 대신 하늘색 덮개(`--sky-top`)를 씌운다. 글자는 남색이다.
  - 글자가 놓이는 영역은 덮개가 92% 이상(`--hero-scrim`)이다. 사진이 완전히 검은 점이어도 본문 9.7:1, 큰 제목의 강조 파랑 3.55:1이다. `tests/design.test.ts`가 계산한다.
  - 강조 파랑은 큰 제목에만 쓰고, 작은 글자는 남색을 쓴다. 넓은 화면에서는 오른쪽으로 갈수록 덮개가 옅어져(55%) 사진이 드러난다.
  - 아래쪽은 구름 띠(`CloudBank`)가 다음 섹션의 흰색으로 이어진다. 뒤쪽 안개층은 90초에 걸쳐 좌우 24px만 천천히 흐른다.
- **로그인·초대·첫 로그인 확인 화면의 머리 띠(`.auth-intro`)**: 하늘색에서 옅은 하늘을 거쳐 페이지 바탕으로 이어진다. 로고 아래에는 구름 섬(`CloudIsland`)이 떠 있다.
- **✦(`Sparkle`)**: 홈 섹션 표시(01~04, BETA), 히어로·로그인 띠의 머리글에만 작게 둔다.
- **바꾸지 않은 곳**: 홈의 남색 '철학' 섹션과 회원 화면의 남색 제목 띠는 그대로 둔다(다크 모드 작업 때 다시 본다).

## 색 토큰

공통 원본은 `app/theme.css`다. 공개 홈페이지·로그인·마이페이지·역할별 회원 화면은 같은 색상 토큰과 `app/globals.css`를 사용한다. `components/public-home.module.css`의 `--home-*` 이름은 모두 이 토큰을 가리키는 별칭이고, 색 값을 직접 쓰지 않는다(`tests/design.test.ts`가 검사한다). Card, Heading, Field, Feedback의 기능은 유지한다. 새 패키지나 외부 폰트를 추가하지 않았다.

아래 표는 2026-10-24 실제 `theme.css` 값이다. 이전 표(#3567B7 등)는 홈 v2 색으로 바꾸면서 갱신되지 않은 상태였다.

- `sky-top`은 작은 보조 글자(#5B6778)가 위에 놓여도 4.58:1이 되도록 정했다. 이보다 짙은 하늘색이면 4.5:1 아래로 내려간다.
- 반투명 색은 `color-mix(in srgb, var(토큰) N%, transparent)`로 만든다.

주요 버튼은 흰색 글자와 남색(brand-action)을 사용한다. Hover #2F6FA8, Active #1E2A3A이며 비활성 버튼은 중립 배경과 짙은 보조 글자로 표시한다. 활성화 중 순간적인 대비 저하를 막기 위해 버튼 색상 전환 애니메이션은 사용하지 않는다. 입력 경계 #78869A와 초점 #2F6FA8은 밝은 표면에서 3:1 이상이다. 성공·주의·오류는 각각 #3F5E31, #76501B, #9A3428과 밝은 전용 배경을 유지한다.

CSS Variables와 Tailwind `@theme inline`을 연결했다. 예: `bg-brand-action text-primary-foreground`, `bg-surface-blue text-ink`. 카드는 12px 모서리와 경계선만 쓴다. Noto Sans KR(빌드 때 자체 호스팅)을 쓰고 본문 15px, 작은 안내는 최소 12px, 모바일 입력은 16px로 표시한다. 교육철학과 수업 안내 문구는 보존했다.

## 이미지

### 공식 앱 아이콘 — 하늘 아이콘 (2026-10-24 교체)

`public/brand/muleum-icon-sky.png`(1254×1254, RGB)는 사용자가 제공한 원본이다. 흰 구름 안에 ?·!가 있는 하늘색 아이콘이고, 둥근 모서리·바깥 그림자·흰 여백이 이미지 안에 그려져 있다. 원본은 고치지 않는다.

| 파일 | 크기 | 만든 방법 | 용도 |
| --- | --- | --- | --- |
| `muleum-icon-sky.png` | 1254 | 원본 그대로 | 화면 로고: 상단 내비게이션, 로그인·초대·첫 로그인 확인 화면, 설치 안내 페이지 |
| `muleum-icon-sky-192.png`, `-512.png` | 192, 512 | 원본을 `sips`로 축소 | PWA manifest `purpose: any`, 알림 아이콘(192) |
| `muleum-icon-sky-maskable-512.png` | 512 | 정사각형 버전을 88.6%로 줄이고 바깥을 가장자리 하늘색으로 이어 채움 | PWA manifest `purpose: maskable` |
| `muleum-icon-sky-apple-180.png` | 180 | 정사각형 버전을 `sips`로 축소 | `apple-touch-icon` |
| `muleum-icon-sky-32.png`, `-16.png` | 32, 16 | 정사각형 버전을 `sips`로 축소 | 파비콘 |

- **정사각형 버전**: 제공된 모서리 없는 원본(full-bleed)이 없어서 직접 만들었다. 원본의 둥근 사각형(가로 147–1105, 세로 146–1104, 959px)을 잘라내고, 모서리·그림자 영역을 주변 하늘색에서 부드럽게 이어 채웠다. 2배 확대하면 아래쪽 모서리에 아주 옅은 경계가 보이지만, 512px 이하 실제 크기에서는 보이지 않는다.
- **maskable 안전 영역**: 구름 윤곽에서 중심까지 가장 먼 점은 왼쪽 아래 덩어리로, 정사각형 너비의 43.8%다. 가운데 80% 원(반지름 40%) 안에 3% 여유를 두고 들어가도록 줄였다.
- **작은 크기의 한계**: 16px 파비콘에서는 물음표가 식별되지 않는다. 32px에서는 흐리게만 보인다. 단순화한 파비콘은 따로 디자인할 예정이다.
- **어두운 배경**: 화면 로고는 원본의 흰 여백까지 그대로 쓴다. 그래서 남색 띠(로그인·초대·첫 로그인 확인 화면) 위에서는 흰 타일처럼 보인다.
- 크기별 비교 이미지: `artifacts/icon-sky/comparison.png`. 이미지 처리에는 macOS `sips`와, 이 컴퓨터에 이미 설치된 Pillow·numpy를 썼다. 프로젝트 의존성은 추가하지 않았다.

## 검증 범위

`tests/design.test.ts`는 정확한 팔레트, Tailwind 연결, 본문 4.5:1 및 초점·입력 경계 3:1 대비를 계산한다. `tests/e2e/community.spec.ts`는 공개·학습 화면 15개 경로, `tests/e2e/auth.spec.ts`는 로그인·다섯 역할 홈·마이페이지의 실제 글자 대비와 가로 넘침을 검사한다. 큰 글자는 3:1 기준이다.

브라우저 검사는 Chrome의 데스크톱 1440×1000, 태블릿 768×1024, 모바일 390×844에서 수행한다. 모바일 왼쪽 메뉴, 큰 화면 상단 메뉴, 키보드 순환·Esc 닫기, 감소된 움직임 설정을 유지한다. 실제 기기의 Safari·Android, 화면낭독기·OS 고대비 모드는 별도 확인이 필요하다. 이 검사는 전체 WCAG 인증을 의미하지 않는다.

졸업생은 계정 상태만 안내하며 내부 라운지·모임·게시판이나 존재하지 않는 외부 링크를 추가하지 않았다. 인증·DB·권한·학습 로직은 디자인 변경 대상이 아니다.
